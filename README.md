# recall-public
## Description
Recall is a Mac OS and iOS study app, combining docs with flashcards. The files included here are the Mac OS dmg, which should be dragged into applications, and the iOS ipa, installed through FlareStore (add this repository's `source.json` as a source).

## Instructions
1. Download one/both of the apps.
2. If you want live sync, deploy your own backend with the Deploy to Cloudflare button in [recall-backend](https://github.com/BCYAYAY14/recall-backend), then connect each app in Settings > Sync.

## Note
This app has not been polished for public release, so if these hurdles are too much, you can always wait for the future when I may release this to the public properly
