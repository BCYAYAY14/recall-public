# recall-public
## Description
Recall is a Mac OS and iOS study app, combining docs with flashcards. The files included here are the Mac OS dmg, which should be dragged into applications, iOS ipa, which must be SIDELOADED (through SideStore, AltStore etc), and the supabase setup sql.

## Instructions
1. Download one/both of the apps.
2. If you want live sync, run the supabase script in SQL editor, and then create an account under Authentication in your supabase project
3. Sign in into your accounts on the apps

## Note
This app has not been polished for public release, so if these hurdles are too much, you can always wait for the future when I may release this to the public properly
